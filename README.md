# PROMPT_AI
Adaptive project planner: answers by clicking, get analysis, stack, roadmap, paste-ready prompts.

## Run locally (Node 18+)
1. `npm install`
2. `cp .env.example .env` and put a free Gemini key (aistudio.google.com/apikey) in it, or an Anthropic key
3. `npm start`, then open http://localhost:3000

Export: Markdown download, or "Save as PDF" (browser print). PowerPoint export is not included yet.
